# 🦙 LLAMA PAJAMAS™ — Official Storefront

**One herd. A million dreams.**

Static storefront for the Llama Pajamas™ merch brand, modeled on the UX structure of leading kids'-pajama DTC stores (hero → category tiles → trust badges → reviews → brand story → collections → promise → newsletter).

## Pages
- `index.html` — homepage
- `shop.html` — product grid with collection filters (`?c=new|bestsellers|alo-chill|kids|grandma|grandpa`)
- `product.html?id=...` — product detail with size/qty picker
- `herd.html` — meet Paco, Lola, Lumi, Lio, Lulu & Puff

## Status
🚧 **Demo mode** — cart works (localStorage), checkout opens soon. No payment is taken.
